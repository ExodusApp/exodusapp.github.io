# Exodus legal pages

Public legal pages for Exodus apps, published at https://exodusapp.github.io/ from the ExodusApp/exodusapp.github.io repository using GitHub Pages.

Each app's pages live under /<app>/, with Flashcards at /flashcards/privacy/ and /flashcards/terms/.

Diego owns these pages. The Flashcards drafts were approved by Diego on 1 November 2026.

The site uses static HTML and inline CSS, with no JavaScript or external assets.
